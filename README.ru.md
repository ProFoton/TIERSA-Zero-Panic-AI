# TIERSA™: Zer0-Panic AI
> **ЗАЩИТА ИИ-НОД ОТ КРИТИЧЕСКИХ СБОЕВ И ВЫГОРАНИЯ КРЕМНИЯ**

Высокопроизводительное программное обеспечение промежуточного слоя (middleware) для съёма низкоуровневой телеметрии и превентивной защиты аппаратных мощностей дата-центров.

---

## 🎯 Миссия проекта

При годовом показателе отказов (AFR) ИИ-кластеров на уровне 9%, физическая деградация оборудования уносит миллиарды долларов. **TIERSA™ Zer0-Panic AI** кардинально меняет экономику ЦОД. Система работает на базе проприетарного Цифрового Двойника (двухмерные фильтры Калмана) и предиктивной аналитики MTBF, локализуя и предотвращая износ кремния до того, как произойдет паника ядра (*kernel panic*) или коллапс интерконнекта *NVLink*.

### Что защищает TIERSA™:
*   **Core (Кристалл):** Защита от электромиграции транзисторных затворов при пиковых ИИ-нагрузках.
*   **HBM (Память):** Снижение термомеханического стресса в сквозных межсоединениях (TSV).
*   **CoWoS / Системные платы:** Предотвращение межслойных микротрещин из-за температурных циклов.
*   **DIGI-VRM (Питание):** Блокировка теплового разгона мосфетов и пробоя фаз питания.

## 🚀 Быстрый запуск (Развертывание за 1 секунду)

Ядро T-RUST оптимизировано методом глубокой LLVM-стерилизации. Исполняемый файл полностью очищен от отладочного мусора, весит **всего ~1 МБ** и готов к автономной работе в изолированных контурах (Air-Gap).

### 1. Скачивание ядра
Скачайте скомпилированный бинарный файл `tiersa_core` из официальной вкладки **Releases** текущего репозитория GitHub.

### 2. Активация суверенной лицензии
Для защиты интеллектуальной собственности и предотвращения несанкционированного развертывания, бинарный файл **не содержит встроенного триального ключа**. При первом запуске без лицензии система выдаст статус `ACCESS > DENIED`.

Чтобы получить персональный **3-дневный изолированный ознакомительный ключ (Evaluation Kit)**, привязанный к вашей аппаратной подписи, отправьте прямой запрос разработчику.

### 3. Развертывание ключа
Поместите полученный файл лицензии строго в корень проекта рядом с бинарником:
```bash
~/T-RUST/
├── tiersa_core        # Скачанный бинарник (~1 МБ)
└── Named_license.key  # Ваш персональный ключ (полученный по запросу)
```

### 4. Боевой пуск
Запустите демон в Linux-среде кластера (Ubuntu/WSL2):
```bash
chmod +x tiersa_core && ./tiersa_core
```
При валидной ЭЦП RSA-PSS (SHA-256) ядро выдаст Enterprise-баннер и развернет OpenMetrics-шлюз на порту `0.0.0.0:8000`.
